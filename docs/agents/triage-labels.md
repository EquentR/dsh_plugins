# Triage Labels

工程 skill 使用以下五个标准 triage 角色；右侧是本仓库 GitHub Issues 中实际使用的 label 名称。

| 标准角色 | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者尚未评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 描述完整，可交给编码代理 |
| `ready-for-human` | `ready-for-human` | 需要人工决策或实现 |
| `wontfix` | `wontfix` | 明确不处理 |

除非已有 label 语义发生变化，不要为同一角色创建别名。issue 可以同时使用领域标签（例如 `plugin:model-capabilities`）和一个 triage 标签。
